# assets/voice — нейро-озвучка диктора

Сюда кладутся озвученные `.mp3` файлы. Полный список того, что нужно
озвучить (имя файла + текст), лежит в [`../../VOICE_LINES.md`](../../VOICE_LINES.md)
и в [`voice_manifest.json`](voice_manifest.json).

Правила:
- Имя файла менять нельзя — приложение ищет ровно эти имена.
- Формат `.mp3`, моно, желательно один и тот же голос/громкость/темп для всех клипов.
- Пока файлов нет — приложение само озвучивает текст системным голосом (flutter_tts).
  Как только появятся настоящие клипы, оно автоматически переключится на них.

Регенерация списка после правок текста: `dart run tool/generate_voice_lines.dart`.
