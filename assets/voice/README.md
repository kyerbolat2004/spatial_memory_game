# assets/voice — нейро-озвучка диктора

Сюда кладутся озвученные `.mp3` файлы. Полный список того, что нужно
озвучить (имя файла + текст), лежит в [`../../VOICE_LINES.md`](../../VOICE_LINES.md)
и в [`voice_manifest.json`](voice_manifest.json).

## Два голоса (мужской / женский)
- **Мужской** (по умолчанию): файлы лежат прямо в `assets/voice/`.
- **Женский**: те же 122 имени файлов, но в подпапке `assets/voice/female/`.

Переключается в приложении: Настройки → «Женский голос диктора».
Если женского клипа нет — приложение возьмёт мужской, а если нет и его — озвучит
системным голосом. Так что наборы можно дополнять по одному.

> Сейчас женский набор — это AI-голос (Svetlana), как заглушка, чтобы
> переключатель работал. Для продакшена запиши все 122 текста настоящим
> женским диктором и положи в `assets/voice/female/` с теми же именами.
> Аналогично 4 мужских клипа (`connector_i_eshe_na`, `intro_edinorog_probuet_poyti`,
> `intro_edinorog_sobiraetsya_poyti`, `intro_osminog_hochet_uplyt`) сейчас AI —
> их тоже стоит переозвучить настоящим мужским диктором.

Правила:
- Имя файла менять нельзя — приложение ищет ровно эти имена.
- Формат `.mp3`, моно, желательно один и тот же голос/громкость/темп для всех клипов.
- Пока файлов нет — приложение само озвучивает текст системным голосом (flutter_tts).
  Как только появятся настоящие клипы, оно автоматически переключится на них.

Регенерация списка после правок текста: `dart run tool/generate_voice_lines.dart`.
